Comment utiliser VidéoPrivée

1. Première ouverture

Ouvre le site ou l’application. Tu arrives sur l’écran de connexion.

2. Connexion ou création de compte

  • Nouveau : « Créer un compte » → e-mail + mot de passe (min. 4 caractères).
  • Déjà un compte : entre e-mail + mot de passe → « Se connecter ».
  • Mot de passe oublié : clique sur le lien → e-mail + nouveau mot de passe.
  • Accès rapide : laisse l’e-mail vide et entre un code maître (hessus, hessuusssss, master, prive ou video123).

Tout est stocké uniquement dans ton navigateur.

3. Une fois connecté

Tu vois le logo, la citation du jour, le bouton ☰, la zone de dépôt de vidéo et la section d’extraction de lien.

4. Envoyer une vidéo

  1. Touche la zone « Glisse-dépose ta vidéo ici » → choisis ton fichier.
  2. Un message vert apparaît : « Vidéo chargée localement. Prête à partager. »
  3. L’aperçu s’affiche en dessous.
  4. Choisis une plateforme pour partager (ouverture manuelle).

5. Gérer les profils

Menu ☰ → « Gérer les profils ». Ajoute un nom de profil pour chaque plateforme (ex. TikTok → « moncompte »). Lors du partage, tu pourras choisir le(s) profil(s).

6. Partager sur les plateformes

Après avoir chargé une vidéo, clique sur une plateforme. L’application ouvre le site. Tu envoies ta vidéo manuellement.

7. Installation

Sur le site web, une carte « Installer l’application » apparaît. Sur Chrome Android : menu ⋮ → « Ajouter à l’écran d’accueil ».
