Comment utiliser VidéoPrivée

1. Première ouverture

Ouvre le site ou l’application. Tu arrives sur l’écran de connexion.

2. Connexion ou création de compte

  • Nouveau : « Créer un compte » → e-mail + mot de passe (min. 4 caractères).
  • Déjà un compte : entre e-mail + mot de passe → « Se connecter ».
  • Mot de passe oublié : clique sur le lien → e-mail + nouveau mot de passe.
  • Accès rapide : laisse l’e-mail vide et entre un code maître (hessus, hessuusssss, master, prive ou video123).

Tout est stocké uniquement dans ton navigateur.

3. Une fois connecté

Tu vois le logo, la citation du jour, le bouton ☰, la zone de dépôt de vidéo et la section d’extraction de lien.

4. Envoyer une vidéo

  1. Glisse-dépose ta vidéo ou clique pour en choisir une (tous formats acceptés).
  2. Aperçu + informations (durée, taille…).
  3. Tu peux télécharger, renommer, copier un lien privé temporaire, partager manuellement ou retirer la vidéo.

5. Partager sur les plateformes

Après avoir chargé une vidéo, clique sur une plateforme (TikTok, Instagram, YouTube, etc.). L’application ouvre le site. Tu envoies ta vidéo manuellement (rien n’est envoyé automatiquement pour rester 100 % privé).

6. Extraire depuis un lien

Colle un lien public → « Préparer le lien ». Ouvre-le manuellement, télécharge la vidéo, puis reviens pour la partager.

7. Menu ☰

  • Mode jour / nuit
  • Langue (Français, English, العربية)
  • Gestion du mot de passe et des profils
  • Cette aide

8. Installation

Sur le site web, une carte « Installer l’application » apparaît. Sur Chrome Android : menu ⋮ → « Ajouter à l’écran d’accueil ». Elle disparaît une fois l’application installée.

Panneau Administrateur

Visible uniquement avec l’e-mail drive.ia01@outlook.com + un code maître. Permet de voir/supprimer les comptes et de réinitialiser toutes les données locales.
